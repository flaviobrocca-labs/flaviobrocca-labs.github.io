# flaviobrocca-labs.github.io

Sitio de Flavio Brocca Labs (GitHub Pages): recursos gratuitos de la serie "Onboarding seguro" y páginas de los kits de inicio.

- `/` — recursos (serie, guía, kits)
- `/kit-emrtd/` — Kit eMRTD Reader

Para habilitar la compra del kit: en `kit-emrtd/index.html`, poner `VENTA_HABILITADA = true` y completar `LINK_POLAR`.
